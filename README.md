# evently_app

> Flutter Events Discovery App with Firebase and smooth UI transitions

---

## About

A beautifully crafted Flutter app for browsing and discovering events, built with Firebase and smooth UI transitions. Supports Arabic & English and Light/Dark mode. Built by [Mustafa Mahmoud](https://mustafa-mahmoud.vercel.app).

### Key Features

- Browse and discover local & global events
- Real-time data with Firebase Firestore
- Arabic & English language support
- Light & Dark mode
- Smooth page transitions and animations

## Tech Stack

| Technology | Version |
|-----------|---------|
| Flutter | >=3.0.0 |
| Dart | >=3.0.0 |
| Firebase | latest |
| AR/EN | support |
